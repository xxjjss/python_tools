# python_tools

这是一个收集若干小型 Python 工具的仓库，根目录下每个子目录对应一个独立工具。当前包含的工具：


**设计理念**：每个工具尽量保持单文件或小目录结构，易于阅读和单独运行。欢迎将你自己的小工具以同样方式加入此仓库。

**快速开始**


```bash
git clone <repo-url>
cd python_tools/cleanup-email
```


**cleanup-email 概览**

`cleanup-email` 是一个通过 IMAP 扫描并删除历史邮件的命令行脚本 — 详见 [cleanup-email/README.md](cleanup-email/README.md)。

其他工具将按同样风格添加到仓库根目录。
